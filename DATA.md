# Data availability

The image corpus is not redistributed with this repository.

The manuscript experiments use source-disjoint train/validation/TEST splits.
All derivatives of a source image must remain in the same split.

Users wishing to reproduce the experiments should obtain the source dataset
from its original distributor and follow the preprocessing and manifest
generation steps in the repository.

Generated caches, contexts, Docker disks, and other machine-local artifacts
are intentionally excluded from version control.
